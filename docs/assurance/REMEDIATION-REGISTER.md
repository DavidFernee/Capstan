The patch replaces C-string parsing with a strict parser bounded by \`CapStr.len\`. It rejects null/negative-length records, embedded NULs, suffix bytes, malformed separators, signs, whitespace, leading zeroes, non-ASCII/non-decimal costs, uppercase/non-hex fields, and any record whose cost is not exactly the current 600,000-iteration generation profile. Salt, expected digest and computed digest scratch are wiped.

Regression coverage in \`tests/unit/test_runtime.c\` includes null arguments; negative record and password lengths forged on valid allocations; leading-zero cost; uppercase hex; embedded-NUL suffix; ordinary trailing suffix; non-ASCII cost byte; 600001 first-over-limit cost; and a 100,000,000-iteration record. A test-only PBKDF2 call counter asserts malformed records are rejected before KDF invocation. A structurally canonical current-format record is checked without running the expensive KDF. The standard test runner compiles this unit file in both normal and ASan+UBSan paths.
