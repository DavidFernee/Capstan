# Native compiler engineering programme — baseline 1.0

Status: proposed control baseline, 2026-11-27. This is a management overlay, not a new language standard. Existing approved specifications govern; unresolved conflicts go to architecture review. RFC #542 is the governing architecture candidate; #544 is a superseded duplicate. #540 and #547/#549 are active implementation/proof work, not completed gates.

## Controlled documents
- CAP-001: [MASTER-REQUIREMENTS](MASTER-REQUIREMENTS.md)
- CAP-002: [SYSTEM-DESIGN](SYSTEM-DESIGN.md)
- CAP-003: [WORK-BREAKDOWN](WORK-BREAKDOWN.md)
- CAP-004: [VERIFICATION-PLAN](VERIFICATION-PLAN.md)
- CAP-005: [CONFIGURATION-MANAGEMENT](CONFIGURATION-MANAGEMENT.md)
- CAP-006: [INTERFACE-CONTROL](INTERFACE-CONTROL.md)
- CAP-007: [SCHEDULE](SCHEDULE.md)

Use the V-model: requirements ↔ acceptance; architecture ↔ system integration; subsystem design ↔ subsystem verification; detailed design ↔ unit tests/proofs. Incremental vertical slices are allowed under frozen versioned interfaces. No 10/10 verdict until all release gates are supported by evidence.
