# G1 B05 / I05 — effects and capability contract candidate

Sources docs/SPEC.md (types, builtins, policy/grant, secrets), C-FREE-EXECUTION.md §§3–5,12, G0-SUPPLEMENTAL-DISPOSITION R06.01–06. G0 HOLD. Proposed secured extension, not a normative amendment.

## Authority and effects
Scalar v0.1 admits no host effects. Later assured profiles require versioned closed effect signatures and validated authority operands; no integer-to-capability conversion, implicit ambient authority or unregistered syscall. Distinguish policy Grant<P> from host resource capability and memory handle. Preserve source authorize-only grant creation, role binding and policy reevaluation at protected call; denial before protected effects, no unchecked annotation grants authority. Host attenuation cannot increase rights; revocation invalidates descendants (proposed), stale generations fail closed, no reuse/wrap. Define grant revalidation separately from host revocation. Existing ambient file APIs and integer workspace descriptors are compatibility/TCB boundaries, not proof of unforgeable authority. fd3 result is launcher authority, not general source output.

## Information flow
Represent Tainted, trusted string and contextual Html/LogText/CsvText distinctly until enforcement; no context interchange or implicit trust. Preserve byte-level provenance through aliases, aggregates, byte extraction/reconstruction, calls and joins; registered validators/escapers have typed success postconditions, failures cannot promote. Explicit trust if permitted by source profile requires an audited policy decision; no new trust escape in assured profile. Sink acceptance keyed to exact context and authority, not name matching. #554 is limited source-analysis evidence, not native refinement. Password hash policy and mandatory bounded-input rules remain separate enforced obligations; reject unsupported effects before emission.

## Secrets and concurrency
Secret storage opaque, pointer-free, cannot be printed/concatenated/read or general equality; preserve existing permitted comparison and cryptographic operations. Equal-length content-independent comparison is scoped, not general constant time. Public lengths and explicitly authorized declassification/results must be documented. Wipe controlled backing before reuse/release; track copies/spills and host environment source copies separately; no claim of wipe on external kill or physical remanence. Initial assured profile single-threaded, no callbacks/signal-time mutation; concurrency needs separately versioned memory/effect model.

## Proof and admission
Define low-equivalence on public inputs, authority and declared observable trace; compare public output, termination/trap, charge and lengths only where included in approved attacker model, explicitly disclose timing/cache/OS exclusions. Taint soundness does not imply relational confidentiality. Prove authority monotonicity, denial-before-effect, grant role correspondence, sink context preservation, secret lifetime and source-to-CCAM/native refinement. Host failures distinct from machine traps (B03/B04); bound input/output and effect attempts before allocation or dispatch, wall timeout separately. No silent compatibility fallback.
